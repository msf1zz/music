# sound

browser live coding music in javascript.

## run

```sh
npm install
npm run dev
```

## tabs

- `welcome` intro and example patterns
- `wiki` functions, synth parameters, and scale references
- `options` master volume, delay, verb, tone controls, and step sequencer roll

## built with

- react
- codemirror
- supersonic / supercollider
- vite

creds to supersonic for engine and favicon.
